# GELASEHOUSE PUBLICATIONS

**Publish Globally. Impact Eternally.**

GELASEHOUSE PUBLICATIONS est la plateforme de publication indépendante de Gelasehouse. Elle est distincte du projet d’intelligence artificielle Houmba H 1 / Houmba Omega.

## Dépôt officiel

- Application : `gelasehouse-publications`
- Branche principale : `main`
- Déploiement statique compatible GitHub Pages

## État actuel

La version actuelle fournit une interface publique responsive avec :

- accueil et présentation de la plateforme ;
- catalogue de publications ;
- auteurs en vedette ;
- formulaire de soumission ;
- pages d’information et contact ;
- fonctionnement côté navigateur sans serveur.

## Limites techniques actuelles

Cette version n’est pas encore une plateforme de production complète : les publications sont locales au navigateur, il n’y a pas encore d’authentification serveur, de base de données distante, de modération persistante, de stockage de fichiers, de paiement ou de panneau d’administration sécurisé.

## Architecture de livraison prévue

1. Interface publique et expérience mobile.
2. Comptes auteurs et authentification sécurisée.
3. API et base de données persistante.
4. Soumission, validation, modération et publication.
5. Profils auteurs, recherche, catégories et statistiques.
6. Téléversement de livres, articles et fichiers multimédias.
7. Abonnements, paiements et revenus auteurs.
8. Notifications, administration, journalisation et sécurité.
9. Tests automatisés, sauvegardes et déploiement continu.

> Important : une application réellement complète nécessite un hébergement backend, une base de données, un stockage de fichiers et des fournisseurs externes configurés. Aucun secret ou mot de passe ne doit être placé dans le dépôt.
